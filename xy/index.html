常见问题

什么是 HTML 实体编码？

把字符转换成 &# + 数字 + ; 的形式。例如「你」是 你，「好」是 好。闲鱼等平台会正常解析并显示为原文，从而避免敏感词命中。

转换会上传我的内容吗？

不会。所有转换都在你的浏览器本地完成，不发送任何网络请求，也不保存任何记录，关闭页面后内容即消失。

支持英文、数字和 emoji 吗？

支持。所有 Unicode 字符都会被转换为对应的数字实体编码，包括英文、数字、特殊符号和 emoji。

复制后对方看到的是编码还是文字？

粘贴到闲鱼聊天框发送时，平台会解析实体编码，对方看到的是正常文字。如果在不支持解析的地方粘贴，可能会显示为 你 形式的原文。

自动复制失败怎么办？

点击「复制走」后若提示失败，请手动选中右侧文本框内容，按 Ctrl + C（Mac 上为 ⌘ + C）复制。

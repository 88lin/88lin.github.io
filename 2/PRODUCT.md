# 88lin 个人网站

<!-- impeccable:product-schema 1 -->

## Platform

web

## Product Purpose

`/2/` 是 88lin（茉灵智库主理人）的个人主页，介绍作者、展示开源项目，并提供个人站点与实用文章入口。本文仅约束 `/2/`，不改变仓库根目录的工具导航站。

## Users

来了解作者、查看开源实践、阅读文章和寻找实用资源的访客。

## Capabilities and Constraints

- 使用静态 HTML、CSS、JavaScript，不引入构建或后端依赖。
- 正式站点为 `https://go.88lin.eu.org/2/`。
- 桌面与手机都可访问；正文、导航与外部链接应在关闭 JavaScript 时仍可阅读。
- 2026-09-20 用户确认新增个人展示画布：展示作者内容，访客可拖动浏览，不开放公共留言。参考 `https://hiesther.me/#system` 的自由画布交互。
- 用户否定第一版规整卡片页，要求更接近参考白板的视觉效果与功能丰富度。画布页采用完整白板布局，提供本地便签、照片、贴纸、涂鸦等交互；公共留言仍不开放。
- 最新反馈要求统一三页手机导航的胶囊形态，修复点击与搜索焦点状态，减缓滚轮缩放，并删除预置咖啡贴纸与可见的灵感来源文字。验收必须覆盖实际鼠标、键盘与触摸交互，不能仅检查静态首屏。
- 项目、站点、文章和身份信息取自现有网页；不虚构生活经历、使用数据或工作成果。
- 用户进一步要求白板按实际内容命名：“博客精选”仅链接博客文章与 https://blog.88lin.eu.org/book 书单，不再链接本站书单旭日图，主页截图标为“个人主页”；不用“书桌一角”“数字花园”等代替内容名称。开源卡片展示具体项目，教程和工具说明与首页、关于页中的事实一致。

## Brand Commitments

主页与关于页保留既有头像、中文衬线标题、黄色强调、悬浮胶囊导航和粉彩气质。画布页按用户最新反馈明确参考 Esther 的整屏点阵白板、蓝色手绘风格与自由拼贴，不再使用第一版的规整信息卡片布局。

用户进一步否定导航米黄、棕金配色。三页导航改为白色底、深色文字和淡紫色选中状态，博客入口使用紫底白字；44 px 点击区内绘制有稳定宽高比的胶囊背景。画布工具按钮和目录同步采用白底、淡紫与深色文字，蓝色继续用于手写内容与纸张。搜索和表单聚焦使用贴合圆角的轮廓，手机输入字号不小于 16 px。

用户指定参考自己的 Lofi Radio 关于页（`https://lofi.88lin.eu.org/about`，“电台是怎么挑出来的”）与电台列表（`https://lofi.88lin.eu.org/stations`）的卡片配色。各页在现有布局上采用清透的粉、紫、蓝、薄荷绿与杏桃色，搭配同色细边；只修饰不协调的色面，保留黄色强调、胶囊导航与白板交互。共享材料由 `assets/palette.css` 管理。

## Evidence on Hand

- `index.html`：项目、站点、精选文章与 GitHub 统计来源。
- `about/index.html`：作者介绍、实践方向、工作方法、技能与联系方式。
- `assets/avatar.webp`：已有个人头像。

## Product Principles

- 新增页面连接现有内容，不重复堆叠完整项目目录。
- 互动帮助探索，手机上保留顺序阅读方式。
- SEO 元数据、内容索引与可见正文保持一致。

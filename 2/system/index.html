白板使用指南

拖动空白处平移，滚轮或双指缩放。卡片可以整张拖动，选中后还能旋转、调整大小；左侧目录会带你找到它。

“贴一张”可添加便签、拍立得、贴纸、名片与待办。“涂鸦”里可以换颜色、调粗细和擦除笔迹。

你的创作仅保存在当前浏览器。原有的个人介绍和链接保持原样，没有公共留言，也不会上传照片。

键盘：方向键平移 / 移动选中卡片，+ / − 缩放，0 查看全貌，Esc 退出画笔或取消选择，Ctrl / ⌘ Z 撤销，Shift + 撤销键重做。

手机也能点右上角的列表图标，切换到顺序阅读。下载菜单可导出图片或备份白板，清理浏览器前记得保存一份。

# 88lin 个人主页

此目录是独立的静态网站，无需安装前端依赖或构建。保留原有居中大标题、黄色高亮、悬浮胶囊导航、MacBook 终端、星光动效和粉彩卡片。

## 本地预览

在仓库根目录运行：

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

打开 `http://127.0.0.1:8765/2/`。关于页为 `/2/about/`，个人展示画布为 `/2/system/`，404 页面为 `/2/404.html`。404 的自动托管行为由部署平台配置决定。

## 文件与维护

- `index.html`：首页内容、项目展示、原有样式与终端动画。
- `about/index.html`：关于页，保留原有内容与视觉设计。
- `system/index.html`：88lin 的白板，使用真实个人内容的可拖动画布；导航入口为“画布”。
- `assets/system.css`、`assets/system.js`：画布布局、缩放、定位、键盘和触摸交互，无外部运行时依赖。
- `assets/navigation.css`：首页、关于页与画布共用的胶囊导航，统一默认、按下、选中和键盘焦点状态。
- `404.html`：错误页；本地资源使用 `/2/` 绝对路径，避免嵌套错误地址解析失败。
- `assets/enhancements.css`：基于原设计的布局、粉彩项目卡片、移动端与无障碍修正。
- `assets/avatar.webp`：由已有 `icon.png` 转换的头像，尺寸 256 × 256；原 PNG 继续用于 Apple Touch Icon。
- `llms.txt`：由页面真实内容生成的个人主页索引，包含项目、站点、文章与作者资料。
- `scripts/build-seo.py`：使用 Python 标准库同步静态 JSON-LD、项目片段地址和内容索引；仅维护时运行。
- `SEO-GEO.md`：SEO / GEO 修改依据、验证记录与发布后的检查步骤。

项目以静态 HTML 交付，不依赖访问者请求 GitHub API。首页先展示 8 个项目，原生 `details` 可展开另外 6 个；关闭 JavaScript 也可浏览全部项目。添加精选项目时更新项目卡片及展开提示；首屏项目总数使用 GitHub 账户公开仓库总数，不等于精选卡片数量。

项目信息于 2026-09-20 核对 GitHub 公开 API、仓库 README 和演示地址。首屏统计为 5,865 Stars、118 个公开仓库，包含 Fork；按 GitHub owner 仓库接口遍历全部分页求和，仓库自身的 Star 数不会继承上游。Stars 是当日快照，更新时同时修改页面注明的日期和单项目徽标。`react-ai-orb` 标注二次开发，`gzh-design-skill` 标注基于上游维护；不把 `fork=false` 等同于原创。TextCard 的有效地址为 `https://88lin.github.io/TextCard-Studio/`。

## 个人展示白板

`/2/system/` 参考 [Esther 的我的 OS](https://hiesther.me/#system)，采用铺满窗口的点阵白板、蓝色手写字、纸胶带、拍立得和贴纸。使用本站已有头像、截图与个人内容，以独立 HTML/CSS/JavaScript 实现；没有接入参考站的数据库。

- 桌面与手机默认自由画布。整张卡片可拖动、旋转、调整大小和置于最前，层次顺序会保存；空白处平移，滚轮或双指缩放。搜索目录、查看全貌与全屏辅助浏览。
- “贴一张”可添加便签、拍立得、贴纸、个人卡片和待办；涂鸦支持五种颜色、粗细与橡皮擦。新增卡片可编辑和删除，待办可勾选。
- 支持撤销与重做；手机可从下载 / 更多菜单操作。键盘聚焦画布后，方向键平移或移动选中卡片，Shift 细调，加减键缩放，`0` 查看全貌，`Ctrl / Cmd + Z` 撤销，`Ctrl / Cmd + Shift + Z` 重做。
- 创作只保存在当前浏览器的 `88lin.whiteboard.v2`。不开放公共留言，不需要账号、数据库或 API Key。照片在本机缩小处理，不上传服务器；更换浏览器或清理站点数据不会自动同步。
- 支持导出 PNG 图片、JSON 备份及恢复。恢复初始摆放保留本地创作；清空创作或导入备份会先提示，也能撤销。存储不可用时保留当前页面的创作并提示备份。
- 切换列表可顺序阅读，关闭 JavaScript 时仍保留九张内容卡片与真实链接，隐藏不可用的编辑工具。
- 原始内容在 `system/index.html` 维护：`data-x` / `data-y` 为坐标，`data-angle` 为角度，`data-width` 为宽度，对应的行内 CSS 变量用于无脚本显示。预置 9 张内容卡片与 2 张贴纸，共 11 个锚点；已删除预置咖啡贴纸和页面上的灵感来源文字，修改后运行 SEO 生成脚本。
- 图片导出使用本地 `assets/vendor/html2canvas.min.js`（1.4.1，MIT，文件保留许可）；字体使用 LXGW WenKai / Caveat，加载失败时回退到系统字体。
- Chromium 对新版进行了两轮有界检查：首轮 24 项、布局修正后 33 项，以及独立复核提出的 14 项专项回归检查，覆盖创建 / 编辑、真实触摸拖动与双指缩放、涂鸦 / 擦除、旋转 / 缩放、撤销重做、PNG 导出、备份恢复、存储失败与无脚本降级；320、390、430、768、1024、1440 px 无页面溢出。
- `2/.impeccable/design.json` 随设计说明维护，临时截图、日志与检查脚本在推送前移出仓库归档；`PRODUCT.md` / `DESIGN.md` 记录此子站的内容约束和视觉规范。

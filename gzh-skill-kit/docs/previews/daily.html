AI 周报 · 十月十五日

本周 AI 圈，
值得记住的 6 件事

没有爆炸性发布，但有几条悄然发生的变化，会在三个月后被证明比发布会更重要。

🫧 模型 · 01

开源模型在长文本上首次反超闭源

长上下文基准刷新纪录，意味着「私有化部署 + 长文档」第一次有了性价比方案。长文本门槛降到个人级。

💸 成本 · 02

两家大厂同步下调 API 价格

降幅 30%~50%，中小开发者的推理成本进一步走低。比拼的是工程效率。

🌐 赛道 · 03

浏览器 Agent 赛道挤进第三个玩家

主打「网页操作回放 + 一键复用」。实测对常见后台操作覆盖不错，复杂表单仍会翻车，建议先从固定流程用起。

⌨️ 工具 · 04

终端 AI 工具开源

命令行直接问「报错什么意思」，中文文档场景友好。

📝 产品 · 05

笔记应用接入 Agent

自动把零散笔记整理成周报，隐私模式支持本地运行。

💡 观点 · 06

「提示词工程师」招聘量腰斩

提示词成基础技能。把一件事写清楚，比堆「咒语」的技巧更值钱。
